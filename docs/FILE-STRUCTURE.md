# File Structure

```
post_training/
├── README.md                 What it is, screenshots, links
├── post_training.md          The project brief (spec, assumptions, changelog)
├── train.py                  Trains one seed through every stage; writes runs/seed<N>/
├── export.py                 Aggregates seeds into site/data/ (+ trajectory gallery)
├── requirements.txt          Python dependencies (torch 2.2.2, numpy<2, pytest)
├── pytest.ini                Test config (adds the repo root to the import path)
├── posttrain/                The Python package
│   ├── env.py                Key & Door gridworld, level generator, BFS expert, reward
│   ├── model.py              Hand-written transformer policy + weight export/import
│   ├── sft.py                Noisy-expert demos, contamination filter, SFT loop
│   ├── rl.py                 GRPO with PPO clipping, KL to SFT, pluggable reward
│   ├── dpo.py                Offline preference pairs + DPO (optional NLL term)
│   ├── hacking.py            The flawed "closeness" proxy reward
│   └── evals.py              Batched rollouts, pass@k, the held-out eval suite
├── tests/
│   ├── test_env.py           Env rules, expert optimality, contamination, pass@k
│   ├── test_parity.py        Python ↔ browser parity, float32 and float16 (runs parity.js in Node)
│   └── parity.js             Node side of the parity test
├── site/                     The project website (static; open index.html)
│   ├── index.html            Page structure
│   ├── style.css             Light/dark theme tokens and layout
│   ├── js/core.js            JS port of the env + transformer forward pass
│   ├── js/charts.js          Small SVG line-chart helper with hover tooltips
│   ├── js/app.js             Race demo, diagram, curves, trajectory fans, eval table
│   └── data/                 Generated by export.py: results.js, checkpoints.js (+ snapshots)
├── runs/                     Generated by train.py: seed<N>/{results.json, partial.json, *.pt, snaps/}, train_seed<N>.log
├── runs_v1/                  Archived first single-seed run (not used by the site)
└── docs/
    ├── INSTRUCTIONS.md       Setup, training, viewing, demo controls
    ├── SYSTEM-DESIGN.md      Architecture, flows, decisions, testing, limits
    ├── FILE-STRUCTURE.md     This file
    └── images/               Screenshots used by the README
```

`.venv/` (local Python environment) and `runs_quick/` (smoke-test output) are
local only and can be deleted.
